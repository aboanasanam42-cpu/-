## 📖 نظرة عامة عن النظام (Overview)

**«التطبيق المحاسبي الطبي الشامل»** هو منظومة برمجية متكاملة مصممة خصيصاً لإدارة العيادات، المستوصفات، والمراكز الطبية التخصصية بدقة محاسبية وإدارية عالية. يجمع النظام بين سرعة تسجيل المرضى، إدارة المعاينات الطبية، قسم المختبرات والتحاليل، قسم الأشعة والسونار، الصيدلية، ومتابعة المصروفات والخرجيات العامة، مع نظام حساب تلقائي لنسب الأطباء والمخبريين وتوليد كشوفات الحسابات والفواتير والتقارير المالية الدورية والنسخ الاحتياطي التلقائي وجدولة الرسائل.

## 🏗️ البنية البرمجية والتقنيات المستخدمة (Architecture & Tech Stack)

- **لغة البرمجة (Language):** Kotlin 100%
- **واجهة المستخدم (UI Framework):** Jetpack Compose مع تطبيق كامل لمعايير Material Design 3 (M3).
- **قاعدة البيانات المحلية (Database):** Android Jetpack Room Database (SQLite محلي ومحمي يعمل بدون إنترنت Offline-First).
- **إدارة الحالة والمسارات (State & Navigation):** Architecture Component (MVVM)، Kotlin Coroutines & StateFlow.
- **التصدير والطباعة (Exporting & Reporting):**
  - توليد ملفات **Excel XLSX** قياسية عبر OpenXML المتكامل.
  - توليد ملفات **PDF** مخصصة للطباعة والمشاركة عبر `android.graphics.pdf.PdfDocument`.
  - تصدير واسترجاع ملفات **JSON** مشفرة لحفظ واسترجاع كامل قاعدة البيانات.
- **الجدولة والتنبيهات (Scheduling & Services):** `AlarmManager` و `BroadcastReceiver` مع دعم أذونات `POST_NOTIFICATIONS` و `SEND_SMS`.

## 🚀 التثبيت والتشغيل عبر GitHub Actions (CI/CD)

يحتوي المستودع على سير عمل مؤتمت بالكامل عبر **GitHub Actions Workflow** يقوم ببناء تطبيق الأندرويد الحقيقي (`.apk`):

1. ادخل إلى تبويب **Actions** في مستودع GitHub الخاص بك.
2. اختر آخر مهمة بناء **Build Android Real APK**.
3. قم بتنزيل ملف الـ **Artifacts** المسمى `MedicalAccounting-Real-APK-debug` أو قم بتنزيل نسخة الـ Release.
4. ثبّت ملف الـ APK مباشرة على هاتفك أو جهازك اللوحي (Tablet).
